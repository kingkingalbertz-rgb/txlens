
# TxLens

TxLens is a small project that helps users understand Ethereum transactions.

## Problem

Blockchain transaction data can be difficult for beginners to understand. TxLens aims to turn raw transaction data into a clear and readable report.

## Goals

- Retrieve transaction data from Ethereum.
- Explain transaction status and gas usage.
- Help users verify results using a block explorer.

## Tech Stack

- Python
- Ethereum JSON-RPC API
- Streamlit (planned)

## Current Status

Project initialized. Implementation has not started yet.
